# hum — 노래방 앱 UI 목업 (Claude Code 전달용)

screens/ 의 HTML 4개가 화면 디자인 원본입니다 (390×844 모바일 기준).
`{{accent}}` 는 포인트 컬러 자리표시자입니다 → 실제 구현 시 #FF5C8A 로 치환하세요.
`<x-dc>`, `<helmet>`, `<script src="./support.js">`, data-dc-script 블록은 디자인 도구 전용이라 구현 시 무시하고, 안의 마크업/스타일만 참고하세요.
곡명·가수·가사는 전부 임의의 예시 데이터입니다.

## 화면 흐름
01 홈 → (검색 탭) 02 곡 검색 → (부르기) 03 노래 부르기 → (종료하기) 04 점수 결과 → (다시 부르기) 03
홈 하단 가운데 마이크 버튼 = 03, 내 노래 탭 = 04

## 디자인 토큰
- 배경 #0E0D14 / 노래 부르기 화면 #0A0911
- 카드/표면 #17161F, 테두리 #2A2833, 구분선 #1E1D27
- 본문 글자 #F4F1EA, 보조 글자 #A09EAE
- 포인트 #FF5C8A (선택지: #8B7CFF, #3DD6C4, #FFB84D) — 포인트 위 글자는 #0E0D14
- 앨범아트 그라디언트: 핑크→보라, 민트→블루, 앰버→레드, 보라→네이비
- 폰트: Noto Sans KR (본문), Space Grotesk (숫자·로고)
- 라운드: 칩/버튼 22px(pill), 카드 24~28px, 앨범아트 12px
- 터치 영역 최소 44px

## 화면별 구성
1. 홈: 로고, 알림, 오늘의 추천 히어로 카드, 장르 칩, 실시간 인기 TOP 4곡(번호 표시), 하단 탭 5개(가운데 마이크 FAB)
2. 곡 검색: 검색창(음성 검색 버튼), 필터(전체/곡명/가수/번호), 결과 리스트(검색어 강조, 노래방 번호), 하단 미리듣기 바 + 부르기 버튼
3. 노래 부르기: 상단 곡 정보·실시간 점수, 음정 바(피치 시각화), 가사 4줄(현재 줄은 왼→오 채워짐 효과), 진행바, 키 −/+, 일시정지, 종료
4. 점수 결과: 원형 점수 링(92점), S 등급, 음정/박자/감정 막대, 내 녹음 파형 재생, 다시 부르기/공유
