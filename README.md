# hum — 노래방 앱

`docs/mockup/` 의 UI 목업(390×844 모바일)을 기반으로 한 웹 프로토타입입니다. 빌드 과정 없이 순수 HTML/CSS/JS(ES 모듈)로 만들었습니다.

## 실행
```bash
python3 -m http.server 8000   # 또는 npx serve .
# → http://localhost:8000
```
마이크를 쓰려면 localhost 또는 HTTPS 에서 열어야 합니다. 마이크 권한이 없으면 데모 모드로 채점됩니다.

## 화면
| 경로 | 화면 |
|---|---|
| `#/` | 홈 — 오늘의 추천, 장르 칩, 실시간 인기 TOP |
| `#/search` | 곡 검색 — 전체/곡명/가수/번호 필터, 검색어 강조, 음성 검색, 미리보기 바 |
| `#/sing/:id` | 노래 부르기 — 실시간 음정(마이크 자기상관 피치 검출), 가사 채움 효과, 키 ±, 일시정지, 녹음 |
| `#/result` | 점수 결과 — 점수 링, 등급, 음정/박자/감정, 내 녹음 재생·공유 |

## 곡 데이터 (`src/data/songs.js`)
- 샘플 곡: **폴킴 – 모든 날, 모든 순간** (키스 먼저 할까요? OST Part.3, 2018). 홈의 "오늘의 추천"과 인기 1위로 노출됩니다.
- 나머지 곡은 목업에 있던 가상 예시 데이터입니다.
- 가사 형식: `[{ t: 시작초, d: 길이초, text }]`

### ⚠️ 가사/음원 저작권
실제 곡의 가사와 반주는 저작권 대상이라 저장소에 넣지 않았습니다. 지금은 `♪ 1절 1번째 소절` 같은 자리표시자로 타이밍만 맞춰 두었습니다.
상용 서비스에 쓰려면 한국음악저작권협회(KOMCA) 이용 허락을 받거나, 라이선스가 포함된 가사·반주 공급사(노래방 MR 제공사 등)와 계약해야 합니다. 그다음 `text` 를 바꾸고 `lyricsLicensed: true` 로 설정하면 됩니다.
